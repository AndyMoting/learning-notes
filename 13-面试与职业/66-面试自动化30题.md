**题1：Selenium的工作原理是什么？**

Selenium通过浏览器驱动（WebDriver）与浏览器进行通信，控制浏览器执行操作。

工作流程：
1. 测试脚本调用Selenium客户端库API
2. 客户端库将命令转换为JSON格式（W3C WebDriver协议）
3. 通过HTTP请求发送给浏览器驱动（ChromeDriver/GeckoDriver）
4. 浏览器驱动接收命令并转换为浏览器原生操作
5. 浏览器执行操作并返回结果
6. 结果经驱动返回给客户端库
7. 客户端库将结果转换为脚本可使用的对象

关键概念：
- **WebDriver协议**：W3C标准化的浏览器自动化协议
- **浏览器驱动**：各浏览器厂商提供的中间件（ChromeDriver、GeckoDriver、EdgeDriver）
- **Selenium Grid**：支持分布式并行执行，Hub-Node架构

**题2：Selenium有哪些元素定位方式？优先级如何？**

8种定位方式（按推荐优先级排序）：

1. **ID**：`driver.find_element(By.ID, "username")`
   - 最快、最稳定，优先使用

2. **Name**：`driver.find_element(By.NAME, "email")`
   - 表单元素常用

3. **CSS Selector**：`driver.find_element(By.CSS_SELECTOR, "input.login-btn")`
   - 灵活、性能好，支持复杂选择器

4. **XPath**：`driver.find_element(By.XPATH, "//input[@id='username']")`
   - 最灵活，支持文本查找和层级导航
   - 性能略差于CSS

5. **ClassName**：`driver.find_element(By.CLASS_NAME, "btn-primary")`
   - 注意：不支持复合类名（含空格）

6. **TagName**：`driver.find_element(By.TAG_NAME, "input")`
   - 通常需要配合其他条件

7. **LinkText**：`driver.find_element(By.LINK_TEXT, "登录")`
   - 仅适用于完整链接文本

8. **PartialLinkText**：`driver.find_element(By.PARTIAL_LINK_TEXT, "登录")`
   - 链接文本模糊匹配

最佳实践：
- 优先使用ID和Name
- 动态元素使用CSS或XPath
- 避免使用绝对XPath（如`/html/body/div[3]/...`）
- 避免使用index定位（如`div[3]`）

**题3：显式等待和隐式等待的区别？**

**隐式等待（Implicit Wait）**：
```python
driver.implicitly_wait(10)  # 全局设置，对所有find_element生效
```
- 设置一次，全局生效
- 轮询查找元素，超时后抛出NoSuchElementException
- 无法针对特定条件（如元素可点击、元素可见）

**显式等待（Explicit Wait）**：
```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 10)
element = wait.until(EC.element_to_be_clickable((By.ID, "submit")))
```
- 针对特定元素、特定条件
- 支持多种条件：可见、可点击、存在、文本变化等
- 超时后抛出TimeoutException

**区别对比**：
| 维度 | 隐式等待 | 显式等待 |
|------|----------|----------|
| 作用范围 | 全局 | 单个操作 |
| 等待条件 | 仅元素存在 | 多种自定义条件 |
| 灵活性 | 低 | 高 |
| 推荐程度 | 不推荐单独使用 | 推荐 |

最佳实践：显式等待为主，可配合隐式等待作为兜底。

```python
# 获取当前窗口句柄
main_window = driver.current_window_handle

# 获取所有窗口句柄
all_windows = driver.window_handles

# 切换到新窗口
for window in all_windows:
    if window != main_window:
        driver.switch_to.window(window)
        break

# 或者直接切换到最新窗口
driver.switch_to.window(driver.window_handles[-1])

# 关闭当前窗口并切回主窗口
driver.close()
driver.switch_to.window(main_window)
```

**题8：Selenium常见异常及处理？**

| 异常 | 原因 | 解决方案 |
|------|------|----------|
| NoSuchElementException | 元素未找到 | 检查定位策略、添加等待、确认iframe |
| TimeoutException | 操作超时 | 增加等待时间、检查网络/性能 |
| StaleElementReferenceException | 元素已失效（DOM刷新） | 重新定位元素、使用显式等待 |
| ElementNotInteractableException | 元素不可交互 | 等待元素可点击、检查元素是否被遮挡 |
| ElementClickInterceptedException | 点击被其他元素遮挡 | 使用JS点击、先关闭遮挡元素 |
| NoSuchWindowException | 窗口不存在 | 确认窗口句柄、先切换窗口 |
| NoSuchFrameException | iframe不存在 | 确认iframe定位、先等待iframe加载 |
| SessionNotCreatedException | 会话创建失败 | 检查浏览器版本与驱动版本匹配 |

通用处理模式：
```python
from selenium.common.exceptions import (
    NoSuchElementException, TimeoutException, StaleElementReferenceException
)

def safe_click(driver, locator, retries=3):
    for attempt in range(retries):
        try:
            element = WebDriverWait(driver, 10).until(
                EC.element_to_be_clickable(locator)
            )
            element.click()
            return True
        except StaleElementReferenceException:
            if attempt == retries - 1:
                raise
            time.sleep(1)
        except ElementClickInterceptedException:
            # 使用JS点击作为备选
            driver.execute_script("arguments[0].click();", element)
            return True
    return False
```

**题11：API测试中如何处理认证？**

```python
import requests

class AuthenticatedClient:
    def __init__(self, base_url):
        self.base_url = base_url
        self.session = requests.Session()
        self.token = None
    
    def login(self, username, password):
        """登录获取Token"""
        response = requests.post(
            f"{self.base_url}/auth/login",
            json={"username": username, "password": password}
        )
        response.raise_for_status()
        self.token = response.json()["access_token"]
        # 设置session默认header
        self.session.headers.update({
            "Authorization": f"Bearer {self.token}"
        })
        return self
    
    def request(self, method, path, **kwargs):
        """统一请求方法，自动处理认证"""
        url = f"{self.base_url}{path}"
        response = self.session.request(method, url, timeout=10, **kwargs)
        
        # Token过期自动刷新
        if response.status_code == 401 and self.token:
            self._refresh_token()
            response = self.session.request(method, url, timeout=10, **kwargs)
        
        return response
    
    def _refresh_token(self):
        """刷新Token"""
        response = self.session.post(f"{self.base_url}/auth/refresh")
        if response.status_code == 200:
            self.token = response.json()["access_token"]
            self.session.headers["Authorization"] = f"Bearer {self.token}"

# 使用示例
client = AuthenticatedClient("https://api.example.com")
client.login("admin", "password")
response = client.request("GET", "/users")
```

**题13：如何测试接口的性能？**

```python
import time
import statistics
import concurrent.futures
import requests

def measure_response_time(url, payload, iterations=100):
    """测量接口响应时间"""
    times = []
    for _ in range(iterations):
        start = time.time()
        response = requests.post(url, json=payload)
        elapsed = (time.time() - start) * 1000  # 毫秒
        times.append(elapsed)
        assert response.status_code == 200
    
    return {
        "min_ms": min(times),
        "max_ms": max(times),
        "avg_ms": statistics.mean(times),
        "median_ms": statistics.median(times),
        "p95_ms": sorted(times)[int(len(times) * 0.95)],
        "p99_ms": sorted(times)[int(len(times) * 0.99)]
    }

def test_concurrent_api():
    """并发测试"""
    url = f"{BASE_URL}/api/orders"
    payload = {"product_id": "P001", "quantity": 1}
    
    def single_request():
        response = requests.post(url, json=payload, timeout=5)
        return response.status_code
    
    with concurrent.futures.ThreadPoolExecutor(max_workers=50) as executor:
        futures = [executor.submit(single_request) for _ in range(200)]
        results = [f.result() for f in concurrent.futures.as_completed(futures)]
    
    success_count = results.count(200)
    success_rate = success_count / len(results)
    assert success_rate >= 0.99, f"成功率{success_rate}低于99%"
```

```python
            "user_id": self.user_id,
            "items": [{"product_id": self.product_id, "quantity": 1}]
        })
        return response.json()
```

**题16：如何设计一个自动化测试框架？**

核心分层架构：

```python
def retry(max_attempts=3, delay=1, exceptions=(Exception,)):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    if attempt < max_attempts:
                        print(f"第{attempt}次失败: {e}，{delay}秒后重试...")
                        time.sleep(delay)
            raise last_exception
        return wrapper
    return decorator
```

**题23：实现一个函数，判断字符串是否为有效括号。**

```python
def is_valid_parentheses(s: str) -> bool:
    """
    判断括号字符串是否有效
    有效：()、()[]{}、{[()]}
    无效：(]、([)]、((()
    
    思路：使用栈，遇到左括号入栈，遇到右括号检查栈顶是否匹配
    时间复杂度：O(n)，空间复杂度：O(n)
    """
    stack = []
    mapping = {')': '(', ']': '[', '}': '{'}
    
    for char in s:
        if char in mapping.values():  # 左括号
            stack.append(char)
        elif char in mapping:  # 右括号
            if not stack or stack[-1] != mapping[char]:
                return False
            stack.pop()
        else:
            continue  # 忽略非括号字符
    
    return len(stack) == 0

# 测试用例
assert is_valid_parentheses("()") == True
assert is_valid_parentheses("()[]{}") == True
assert is_valid_parentheses("{[()]}") == True
assert is_valid_parentheses("(]") == False
assert is_valid_parentheses("([)]") == False
assert is_valid_parentheses("((()") == False
assert is_valid_parentheses("") == True
```

**题24：实现一个函数，找出数组中重复的数字。**

```python
def find_duplicates(arr: list) -> list:
    """
    找出数组中所有重复的数字
    时间复杂度：O(n)，空间复杂度：O(n)
    """
    seen = set()
    duplicates = set()
    
    for num in arr:
        if num in seen:
            duplicates.add(num)
        else:
            seen.add(num)
    
    return list(duplicates)

def find_duplicate_in_place(arr: list) -> int:
    """
    找出1~n范围内数组中的重复数字（数组长度n+1）
    不额外使用空间，修改原数组
    时间复杂度：O(n)，空间复杂度：O(1)
    """
    for i in range(len(arr)):
        while arr[i] != i:
            if arr[i] == arr[arr[i]]:
                return arr[i]
            # 交换arr[i]和arr[arr[i]]
            temp = arr[i]
            arr[i] = arr[temp]
            arr[temp] = temp
    return -1

# 测试
assert find_duplicates([1, 2, 3, 2, 4, 3, 5]) == [2, 3]
assert find_duplicate_in_place([1, 3, 4, 2, 2]) == 2
```

```python
                        test_func(**data)

                        raise AssertionError(f"数据{i}失败: {e}")
```

**题28：实现一个简单的重试装饰器（带指数退避）。**

```python
import time
import functools
import random

def retry_with_backoff(max_attempts=3, base_delay=1, max_delay=60, 
                       exceptions=(Exception,), backoff_factor=2):
    """
    带指数退避的重试装饰器
    
    第1次重试：等待 base_delay * backoff_factor^0 = 1s
    第2次重试：等待 base_delay * backoff_factor^1 = 2s
    第3次重试：等待 base_delay * backoff_factor^2 = 4s
    每次延迟添加±25%的随机抖动，避免惊群效应
    """
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    
                    if attempt == max_attempts - 1:
                        break
                    
                    # 计算延迟（指数退避 + 随机抖动）
                    delay = min(
                        base_delay * (backoff_factor ** attempt) + random.uniform(0, base_delay * 0.25),
                        max_delay
                    )
                    
                    print(f"[重试] {func.__name__} 第{attempt+1}次失败: {e}")
                    print(f"[重试] 等待{delay:.1f}秒后重试...")
                    time.sleep(delay)
            
            raise last_exception
        
        return wrapper
    return decorator

# 使用
@retry_with_backoff(max_attempts=3, base_delay=1, exceptions=(ConnectionError, TimeoutError))
def call_external_api():
    response = requests.get("https://api.unstable.com/data", timeout=5)
    response.raise_for_status()
    return response.json()
```

```python
    error: str = ""

class SimpleTestRunner:
    """简单测试执行器，支持串行和并发执行"""
    
    def __init__(self, max_workers=4):
        self.tests = []
        self.max_workers = max_workers
        self.results = []
    
    def add_test(self, name: str, func: Callable, *args, **kwargs):
        self.tests.append({"name": name, "func": func, "args": args, "kwargs": kwargs})
        return self
    
    def run_serial(self):
        """串行执行"""
        self.results = []
        for test in self.tests:
            result = self._execute_single(test)
            self.results.append(result)
        return self
    
    def run_parallel(self):
        """并发执行"""
        self.results = []
        with concurrent.futures.ThreadPoolExecutor(max_workers=self.max_workers) as executor:
            futures = {
                executor.submit(self._execute_single, test): test["name"]
                for test in self.tests
            }
            for future in concurrent.futures.as_completed(futures):
                self.results.append(future.result())
        return self
    
    def _execute_single(self, test) -> TestResultItem:
        start = time.time()
        try:
            test["func"](*test["args"], **test["kwargs"])
            return TestResultItem(
                name=test["name"],
                status="PASS",
                duration=time.time() - start
            )
        except AssertionError as e:
            return TestResultItem(
                name=test["name"],
                status="FAIL",
                duration=time.time() - start,
                error=str(e)
            )
        except Exception as e:
            return TestResultItem(
                name=test["name"],
                status="ERROR",
                duration=time.time() - start,
                error=str(e)
            )
    
    def report(self):
        """生成执行报告"""
        total = len(self.results)
        passed = sum(1 for r in self.results if r.status == "PASS")
        failed = sum(1 for r in self.results if r.status == "FAIL")
        errors = sum(1 for r in self.results if r.status == "ERROR")
        total_time = sum(r.duration for r in self.results)
        
        print(f"\n{'='*60}")
        print(f"测试执行报告 - {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")
        print(f"{'='*60}")
        print(f"总计: {total} | 通过: {passed} | 失败: {failed} | 错误: {errors}")
        print(f"通过率: {passed/total*100:.1f}% | 总耗时: {total_time:.2f}s")
        print(f"{'='*60}")
        
        for r in self.results:
            status_icon = "✓" if r.status == "PASS" else "✗"
            print(f"  {status_icon} {r.name} ({r.duration:.2f}s)")
            if r.error:
                print(f"     {r.error}")

# 使用示例
def test_add():
    assert 1 + 1 == 2

def test_sub():
    assert 3 - 1 == 2

def test_fail():
    assert 1 == 2, "故意失败"

runner = SimpleTestRunner(max_workers=2)
runner.add_test("加法测试", test_add)
runner.add_test("减法测试", test_sub)
runner.add_test("失败测试", test_fail)
runner.run_parallel().report()
```

## 常见坑

1. **代码题只写思路不写代码**：面试官要求手写代码时必须写，思路只是辅助
2. **忽略异常处理**：代码没有try-catch显得不专业
3. **变量命名不规范**：使用a、b、c等无意义名称扣分
4. **不分析复杂度**：写完代码主动说明时间/空间复杂度
5. **过度设计**：简单问题写大量设计模式，显得不切实际
6. **不测试自己的代码**：写完应主动说明测试用例
