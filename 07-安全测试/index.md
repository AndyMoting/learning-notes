## 学习目标

- 掌握 OWASP Top 10 (2021) 全部风险类别的攻击原理与测试方法
- 使用 Burp Suite 和 ZAP 进行漏洞扫描、拦截代理和手动测试
- 针对注入、鉴权失效、XSS、CSRF 等风险独立设计测试用例
- 输出符合行业标准的安全测试报告（含 CVSS 漏洞评级）

## 自测汇总

- [ ] 能解释 OWASP Top 10 每类风险的原理与防御方案
- [ ] 能用 Burp Suite 拦截并修改 HTTP 请求
- [ ] 能使用 SQLMap 检测 SQL 注入漏洞
- [ ] 能编写安全测试报告并给出 CVSS 评分
