## 学习目标

- 理解六种性能测试类型及其关键性能指标（TPS/QPS/RT/并发数）
- 使用 JMeter 设计、执行和分析负载测试场景
- 掌握参数化、关联、逻辑控制器等 JMeter 核心组件
- 搭建 JMeter 分布式压测环境并生成可视化报告
- 使用 Locust 编写 Python 压测脚本实现代码化性能测试
- 使用监控工具定位系统瓶颈并提出调优方案

## 自测汇总

- [ ] 能区分负载/压力/尖峰/耐久/场景/容量测试
- [ ] 能用 JMeter 完成参数化和关联的高级场景
- [ ] 能搭建 JMeter 分布式集群并合并报告
- [ ] 能用 Locust 编写自定义压测脚本
- [ ] 能使用监控指标定位 CPU/内存/网络瓶颈
