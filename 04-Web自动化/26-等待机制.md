# 26-等待机制
> 课时：40 min | 难度：★★★☆☆

## 学习目标

- 理解 Web 自动化中等待机制的必要性与触发场景
- 掌握隐式等待与显式等待的差异及适用场景
- 能使用 WebDriverWait 配合 expected_conditions 处理常见等待条件
- 能编写自定义等待条件（lambda 与函数）
- 能配置 Fluent Wait 实现灵活轮询
- 识别并避免 `time.sleep` 滥用

## 核心概念

### 为什么需要等待

Web 页面加载涉及多种异步行为，直接操作未就绪的元素会抛出 `NoSuchElementException` 或 `ElementNotInteractableException`。

**触发等待的场景：**

| 场景 | 说明 |
|------|------|
| 页面加载 | 导航后 DOM 未完全渲染 |
| AJAX 请求 | 数据异步返回，元素延迟出现 |
| 动画过渡 | CSS 动画/过渡期间元素不可交互 |
| 懒加载 | 图片/列表滚动后加载 |
| 弹窗/Alert | 异步弹出的对话框 |
| iframe 切换 | iframe 内容加载延迟 |
| 前端框架渲染 | React/Vue/Angular 异步更新 DOM |

### 等待策略对比

| 维度 | 隐式等待 | 显式等待 | Fluent Wait |
|------|----------|----------|-------------|
| 作用范围 | 全局（所有 find_element） | 特定条件 | 特定条件 |
| 轮询间隔 | 固定（0.5s 默认） | 可配置 | 可配置 |
| 超时时间 | 全局统一 | 每个条件独立 | 每个条件独立 |
| 条件类型 | 仅元素存在 | 丰富预定义条件 | 自定义条件 |
| 异常处理 | 统一抛异常 | 可忽略特定异常 | 可忽略特定异常 |
| 推荐程度 | 辅助 | 主力 | 高级场景 |

### 三种等待方式

| 方式 | 机制 | 适用场景 |
|------|------|----------|
| 隐式等待 | 全局轮询查找 | 简单页面，元素加载时间一致 |
| 显式等待 | 条件触发等待 | 大多数场景（推荐） |
| Fluent Wait | 自定义轮询+忽略异常 | 复杂条件，不稳定环境 |

## 动手实操

### 隐式等待

```python
from selenium import webdriver

driver = webdriver.Chrome()
driver.implicitly_wait(10)  # 全局隐式等待 10 秒

# 所有 find_element 调用都会在 10 秒内轮询
driver.get("https://example.com")
element = driver.find_element("id", "dynamic-content")
# 如果元素不存在，每 0.5 秒重试一次，直到 10 秒后抛出 NoSuchElementException
```

**隐式等待的局限：**

```python
# 隐式等待只判断元素是否存在，不判断是否可点击/可见
driver.implicitly_wait(5)

# 元素存在于 DOM 但不可点击（如被遮罩），隐式等待不会等待
button = driver.find_element("id", "submit-btn")
button.click()  # 可能抛出 ElementNotInteractableException

# 隐式等待无法等待文本变化
element = driver.find_element("id", "status")
# 无法等待 element.text == "完成"
```

### 显式等待：WebDriverWait + expected_conditions

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get("https://example.com")

# 基本显式等待
wait = WebDriverWait(driver, timeout=10, poll_frequency=0.5)

# 1. 元素可见（存在于 DOM 且宽高 > 0）
element = wait.until(
    EC.visibility_of_element_located((By.ID, "dynamic-content"))
)

# 2. 元素可点击
button = wait.until(
    EC.element_to_be_clickable((By.CSS_SELECTOR, "button.submit"))
)

# 3. 元素存在于 DOM（不一定可见）
element = wait.until(
    EC.presence_of_element_located((By.XPATH, "//div[@class='result']"))
)

# 4. 元素不可见/消失（等待加载动画消失）
wait.until(
    EC.invisibility_of_element_located((By.ID, "loading-spinner"))
)

# 5. 文本出现在元素中
wait.until(
    EC.text_to_be_present_in_element((By.ID, "status"), "完成")
)

# 6. 文本出现在元素 value 属性中（如 input）
wait.until(
    EC.text_to_be_present_in_element_value((By.ID, "search-input"), "关键词")
)

# 7. Alert 弹窗出现
alert = wait.until(EC.alert_is_present())
alert.accept()

# 8. 页面标题包含指定文本
wait.until(EC.title_contains("首页"))

# 9. 页面标题完全匹配
wait.until(EC.title_is("登录成功"))

# 10. 元素被选中（checkbox/radio）
wait.until(EC.element_to_be_selected((By.ID, "agree-checkbox")))

# 11. 元素定位器存在至少一个元素
elements = wait.until(
    EC.presence_of_all_elements_located((By.CSS_SELECTOR, ".item"))
)

# 12. 元素可见（返回所有匹配元素）
elements = wait.until(
    EC.visibility_of_all_elements_located((By.CSS_SELECTOR, ".card"))
)

# 13. 框架可用并切换到该框架
wait.until(
    EC.frame_to_be_available_and_switch_to_it((By.ID, "iframe-content"))
)

# 14. 元素属性包含指定值
wait.until(
    EC.element_attribute_to_include((By.ID, "progress"), "data-loaded")
)

# 15. 元素 staleness（元素从 DOM 移除，用于页面刷新检测）
old_element = driver.find_element("id", "old-content")
wait.until(EC.staleness_of(old_element))
```

### 自定义等待条件

```python
from selenium import webdriver
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("https://example.com")


# 方式一：Lambda 表达式
def wait_for_element_text(driver):
    """等待元素文本等于指定值"""
    element = driver.find_element(By.ID, "status")
    return element.text == "就绪"

WebDriverWait(driver, 10).until(wait_for_element_text)


# 方式二：函数返回元素（非布尔值）
def wait_for_element_count(driver):
    """等待元素数量达到指定值"""
    elements = driver.find_elements(By.CSS_SELECTOR, ".list-item")
    return len(elements) >= 5

WebDriverWait(driver, 10).until(wait_for_element_count)


# 方式三：自定义条件类
class element_has_css_class:
    """等待元素包含指定 CSS 类"""

    def __init__(self, locator, css_class):
        self.locator = locator
        self.css_class = css_class

    def __call__(self, driver):
        element = driver.find_element(*self.locator)
        if self.css_class in element.get_attribute("class"):
            return element
        return False


wait = WebDriverWait(driver, 10)
element = wait.until(
    element_has_css_class((By.ID, "notification"), "active")
)


# 方式四：等待 AJAX 请求完成（jQuery）
def wait_for_ajax(driver):
    """等待所有 jQuery AJAX 请求完成"""
    return driver.execute_script("return jQuery.active == 0")

WebDriverWait(driver, 10).until(wait_for_ajax)


# 方式五：等待页面完全加载
def wait_for_page_load(driver):
    """等待 document.readyState 为 complete"""
    return driver.execute_script("return document.readyState") == "complete"

WebDriverWait(driver, 10).until(wait_for_page_load)


# 方式六：等待 Angular 应用稳定
def wait_for_angular(driver):
    """等待 Angular 无待处理请求"""
    return driver.execute_script(
        "return angular.element(document.body).injector().get('$http').pendingRequests.length == 0"
    )

WebDriverWait(driver, 10).until(wait_for_angular)


# 方式七：等待元素数量稳定（不再变化）
def wait_for_stable_element_count(locator, stability_seconds=2):
    """等待元素数量在指定秒数内不再变化"""
    previous_count = 0
    stable_start = None

    def _check(driver):
        nonlocal previous_count, stable_start
        current_count = len(driver.find_elements(*locator))

        if current_count != previous_count:
            previous_count = current_count
            stable_start = None
            return False

        if stable_start is None:
            stable_start = time.time()
            return False

        if time.time() - stable_start >= stability_seconds:
            return True

        return False

    return _check

WebDriverWait(driver, 30).until(
    wait_for_stable_element_count((By.CSS_SELECTOR, ".lazy-item"), stability_seconds=2)
)
```

### Fluent Wait 配置

```python
from selenium import webdriver
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.common.by import By
from selenium.common.exceptions import (
    NoSuchElementException,
    StaleElementReferenceException,
    ElementNotVisibleException,
)

driver = webdriver.Chrome()
driver.get("https://example.com")

# Fluent Wait：自定义轮询间隔 + 忽略特定异常
wait = WebDriverWait(
    driver,
    timeout=30,           # 最大等待 30 秒
    poll_frequency=1,     # 每 1 秒轮询一次
    ignored_exceptions=[  # 轮询期间忽略这些异常
        NoSuchElementException,
        StaleElementReferenceException,
        ElementNotVisibleException,
    ]
)

# 使用 Fluent Wait
element = wait.until(
    EC.element_to_be_clickable((By.ID, "retry-btn"))
)
element.click()


# 封装为可复用的等待工具类
class WaitHelper:
    """等待工具类，封装常用等待操作"""

    def __init__(self, driver, timeout=10, poll_frequency=0.5):
        self.driver = driver
        self.wait = WebDriverWait(
            driver,
            timeout=timeout,
            poll_frequency=poll_frequency,
            ignored_exceptions=[
                NoSuchElementException,
                StaleElementReferenceException,
            ]
        )

    def for_element_visible(self, locator):
        return self.wait.until(EC.visibility_of_element_located(locator))

    def for_element_clickable(self, locator):
        return self.wait.until(EC.element_to_be_clickable(locator))

    def for_element_present(self, locator):
        return self.wait.until(EC.presence_of_element_located(locator))

    def for_text_in_element(self, locator, text):
        return self.wait.until(EC.text_to_be_present_in_element(locator, text))

    def for_invisibility(self, locator):
        return self.wait.until(EC.invisibility_of_element_located(locator))

    def for_alert(self):
        return self.wait.until(EC.alert_is_present())

    def for_custom(self, condition, message="等待超时"):
        return self.wait.until(condition, message)


# 使用工具类
wait = WaitHelper(driver, timeout=15)
element = wait.for_element_clickable((By.ID, "submit"))
element.click()
wait.for_text_in_element((By.ID, "result"), "成功")
```

### 等待策略综合示例

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.common.exceptions import TimeoutException

driver = webdriver.Chrome()
driver.implicitly_wait(3)  # 短隐式等待作为兜底
wait = WebDriverWait(driver, 15)


def safe_click(locator, timeout=15):
    """安全点击：等待可点击后执行，失败重试"""
    try:
        element = WebDriverWait(driver, timeout).until(
            EC.element_to_be_clickable(locator)
        )
        element.click()
    except TimeoutException:
        # 尝试 JS 点击作为降级方案
        element = driver.find_element(*locator)
        driver.execute_script("arguments[0].click();", element)


def wait_and_input(locator, text, clear_first=True):
    """等待元素可见后输入文本"""
    element = wait.until(EC.visibility_of_element_located(locator))
    if clear_first:
        element.clear()
    element.send_keys(text)
    return element


def wait_for_page_ready(driver, timeout=30):
    """等待页面完全就绪：DOM + AJAX + 动画"""
    WebDriverWait(driver, timeout).until(
        lambda d: d.execute_script("return document.readyState") == "complete"
    )
    # 等待 jQuery AJAX（如果页面使用 jQuery）
    try:
        WebDriverWait(driver, 5).until(
            lambda d: d.execute_script("return typeof jQuery == 'undefined' || jQuery.active == 0")
        )
    except TimeoutException:
        pass  # 页面可能未使用 jQuery


# 实际测试场景
driver.get("https://example.com/dashboard")

# 1. 等待页面加载完成
wait_for_page_ready(driver)

# 2. 等待侧边栏动画结束
wait.for_invisibility((By.ID, "sidebar-animation"))

# 3. 等待数据表格加载
wait.for_element_visible((By.ID, "data-table"))

# 4. 等待加载动画消失
wait.for_invisibility((By.CSS_SELECTOR, ".loading-overlay"))

# 5. 等待数据行出现
rows = wait.for_custom(
    lambda d: d.find_elements(By.CSS_SELECTOR, ".data-row") if len(d.find_elements(By.CSS_SELECTOR, ".data-row")) > 0 else False
)

# 6. 点击分页按钮
safe_click((By.CSS_SELECTOR, ".next-page"))

# 7. 等待当前页数据刷新（staleness 检测）
old_row = driver.find_element(By.CSS_SELECTOR, ".data-row:first-child")
wait.until(EC.staleness_of(old_row))
wait.for_element_present((By.CSS_SELECTOR, ".data-row:first-child"))
```

## 常见坑

1. **隐式等待与显式等待混用**：同时设置隐式等待和显式等待会导致等待时间叠加。例如隐式等待 10s + 显式等待 10s = 最长 20s。建议隐式等待设为 0 或极小值，统一使用显式等待。

2. **隐式等待的 find_elements 陷阱**：`find_elements`（复数）在隐式等待下，如果找不到元素会等待完整超时后返回空列表，而非立即返回。

3. **StaleElementReferenceException**：等待后获取了元素引用，但在操作前 DOM 被更新（如 React 重新渲染），导致元素引用失效。应在操作前重新查找或使用 Fluent Wait 忽略此异常。

4. **visibility vs presence**：`presence_of_element_located` 只检查 DOM 中存在，元素可能不可见或不可点击。需要交互时使用 `visibility_of_element_located` 或 `element_to_be_clickable`。

5. **轮询频率过高**：`poll_frequency` 设置过小（如 0.1s）会增加 CPU 负担，对远程测试服务也可能造成请求压力。一般 0.5s~1s 为宜。

6. **忽略异常过多**：`ignored_exceptions` 列表过长会掩盖真正的问题。只忽略预期内的异常（如 `NoSuchElementException`），避免忽略 `AssertionError` 等。

7. **time.sleep 滥用**：硬编码等待导致测试不稳定（等待不足）或低效（等待过长）。仅在无法使用显式等待的场景（如等待文件下载完成）使用 `time.sleep`。

8. **WebDriverWait 复用问题**：`WebDriverWait` 实例可以复用，但注意 `ignored_exceptions` 只在构造时设置，无法动态修改。
