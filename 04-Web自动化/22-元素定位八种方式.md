- 能在实际页面中选择最优定位方式

## 核心概念

### 定位策略总览

Selenium 提供八种定位策略，均通过 `By` 类调用：

| 策略 | 方法 | 适用场景 |
|------|------|----------|
| ID | `By.ID` | 元素有唯一 id 属性 |
| Name | `By.NAME` | 表单元素有 name 属性 |
| Class Name | `By.CLASS_NAME` | 元素有稳定 class（不含空格） |
| Tag Name | `By.TAG_NAME` | 按标签类型定位（如所有 `<a>`） |
| Link Text | `By.LINK_TEXT` | 精确匹配链接文本 |
| Partial Link Text | `By.PARTIAL_LINK_TEXT` | 模糊匹配链接文本 |
| CSS Selector | `By.CSS_SELECTOR` | 灵活组合，性能优于 XPath |
| XPath | `By.XPATH` | 最强大，支持层级与轴查询 |

### 定位优先级

```
ID > Name > CSS Selector > XPath > Class Name > Tag Name > Link Text
```

优先使用 ID 和 Name（唯一性高、性能最优）；CSS Selector 次之（语法简洁、浏览器原生支持）；XPath 作为兜底方案（功能最强但性能最低、可读性差）。

## 八种定位方式详解

### 1. By.ID

通过 HTML `id` 属性定位，要求 id 在页面中唯一。

```python
from selenium.webdriver.common.by import By

username = driver.find_element(By.ID, "username")
password = driver.find_element(By.ID, "password")
submit_btn = driver.find_element(By.ID, "submit-btn")
```

### 2. By.NAME

通过 HTML `name` 属性定位，常用于表单元素。

```python
username = driver.find_element(By.NAME, "username")
password = driver.find_element(By.NAME, "password")
remember = driver.find_element(By.NAME, "remember")
```

### 3. By.CLASS_NAME

通过单个 class 值定位。**不支持多 class**（含空格的 class 属性值会报错）。

```python
# 正确：定位单个 class
title = driver.find_element(By.CLASS_NAME, "form-title")

# 错误：By.CLASS_NAME 不支持空格分隔的多 class
# driver.find_element(By.CLASS_NAME, "btn btn-primary")  # 抛出 InvalidSelectorException

# 多 class 应改用 CSS Selector
submit_btn = driver.find_element(By.CSS_SELECTOR, ".btn.btn-primary")
```

### 4. By.TAG_NAME

通过 HTML 标签名定位，通常用于获取同类元素集合。

```python
all_inputs = driver.find_elements(By.TAG_NAME, "input")
all_links = driver.find_elements(By.TAG_NAME, "a")
```

### 5. By.LINK_TEXT

精确匹配 `<a>` 标签的完整文本内容。

```python
register_link = driver.find_element(By.LINK_TEXT, "还没有账号？立即注册")
```

### 6. By.PARTIAL_LINK_TEXT

模糊匹配 `<a>` 标签的部分文本内容。

```python
register_link = driver.find_element(By.PARTIAL_LINK_TEXT, "注册")
forgot_link = driver.find_element(By.PARTIAL_LINK_TEXT, "忘记")
```

### 7. By.CSS_SELECTOR

CSS 选择器语法，支持属性选择器、伪类、组合器。

#### 基础语法

```python
# ID 选择器
driver.find_element(By.CSS_SELECTOR, "#username")

# Class 选择器
driver.find_element(By.CSS_SELECTOR, ".form-title")

# 多 class
driver.find_element(By.CSS_SELECTOR, ".btn.btn-primary")

# 标签选择器
driver.find_element(By.CSS_SELECTOR, "button")
```

#### 属性选择器

```python
# 精确匹配属性值
driver.find_element(By.CSS_SELECTOR, "input[name='username']")

# 属性值以某字符串开头
driver.find_element(By.CSS_SELECTOR, "input[name^='user']")

# 属性值以某字符串结尾
driver.find_element(By.CSS_SELECTOR, "input[name$='name']")

# 属性值包含某字符串
driver.find_element(By.CSS_SELECTOR, "input[name*='ser']")

# 属性存在（不限值）
driver.find_element(By.CSS_SELECTOR, "input[placeholder]")
```

#### 组合器

```python
# 后代选择器（空格）：form 内任意层级
driver.find_element(By.CSS_SELECTOR, "form .input-field")

# 子选择器（>）：直接子元素
driver.find_element(By.CSS_SELECTOR, "form > h2")

# 相邻兄弟选择器（+）：紧跟其后的同级元素
driver.find_element(By.CSS_SELECTOR, "input + label")

# 通用兄弟选择器（~）：之后所有同级元素
driver.find_elements(By.CSS_SELECTOR, "div.form-group ~ div.form-group")
```

#### 伪类

```python
# 第一个子元素
driver.find_element(By.CSS_SELECTOR, "div.form-group:first-child")

# 最后一个子元素
driver.find_element(By.CSS_SELECTOR, "div.form-group:last-child")

# 第 n 个子元素
driver.find_element(By.CSS_SELECTOR, "div.form-group:nth-child(2)")

# 否定伪类
driver.find_elements(By.CSS_SELECTOR, "input:not([type='submit'])")
```

### 8. By.XPath

XPath（XML Path Language）通过路径表达式定位节点，功能最强大。

#### 绝对路径 vs 相对路径

```python
# 绝对路径（从根节点开始，脆弱，不推荐）
driver.find_element(By.XPATH, "/html/body/form/div[1]/input")

# 相对路径（从任意位置开始，推荐）
driver.find_element(By.XPATH, "//input[@id='username']")
```

#### 常用函数

```python
# contains()：属性值包含某字符串
driver.find_element(By.XPATH, "//input[contains(@class, 'input-field')]")

# starts-with()：属性值以某字符串开头
driver.find_element(By.XPATH, "//input[starts-with(@id, 'user')]")

# text()：精确匹配文本
driver.find_element(By.XPATH, "//button[text()='登录']")

# contains(text(), ...)：模糊匹配文本
driver.find_element(By.XPATH, "//a[contains(text(), '注册')]")
```

#### 轴（Axes）

```python
# ancestor：祖先节点
driver.find_element(By.XPATH, "//input[@id='username']/ancestor::form")

# descendant：后代节点
driver.find_element(By.XPATH, "//form//input")

# following-sibling：之后同级节点
driver.find_element(By.XPATH, "//input[@id='username']/following-sibling::label")

# preceding-sibling：之前同级节点
driver.find_element(By.XPATH, "//input[@id='password']/preceding-sibling::label")

# parent：父节点
driver.find_element(By.XPATH, "//input[@id='username']/parent::div")
```

#### 多条件组合

```python
# and 条件
driver.find_element(By.XPATH, "//input[@type='text' and @name='username']")

# or 条件
driver.find_element(By.XPATH, "//input[@id='username' or @id='email']")
```

## 综合示例：登录页面定位

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("http://localhost:8080/login")

# ID 定位（最优）
username = driver.find_element(By.ID, "username")
password = driver.find_element(By.ID, "password")

# Name 定位
remember = driver.find_element(By.NAME, "remember")

# CSS Selector 定位
submit_btn = driver.find_element(By.CSS_SELECTOR, "button.btn-primary")

# XPath 定位（兜底）
register_link = driver.find_element(By.XPATH, "//a[contains(text(), '注册')]")

username.send_keys("admin")
password.send_keys("123456")
remember.click()
submit_btn.click()

driver.quit()
```

## 常见坑

1. **By.CLASS_NAME 不支持多 class** — `By.CLASS_NAME, "btn btn-primary"` 会抛出 `InvalidSelectorException`，应改用 CSS Selector
2. **XPath 绝对路径脆弱** — 页面结构微调即失效，始终使用相对路径 `//`
3. **find_element vs find_elements** — 前者找不到抛 `NoSuchElementException`，后者返回空列表
4. **动态 ID** — 若 id 含随机后缀（如 `button-1a2b3c`），使用 `contains()` 或 `starts-with()` 匹配
5. **XPath 性能** — 在大型 DOM 中 XPath 比 CSS Selector 慢，优先使用 CSS
6. **iframe 内元素** — 需先 `driver.switch_to.frame()` 切换上下文，否则定位不到
