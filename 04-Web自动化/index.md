## 学习目标

- 掌握 Selenium WebDriver 架构与元素定位策略
- 使用 Page Object 模式设计可维护的 UI 自动化框架
- 使用 Pytest 组织测试用例、管理 fixture、执行参数化
- 理解并应用三种等待机制处理异步加载场景
- 使用 Playwright 进行现代 Web 应用的跨浏览器自动化
- 集成 visual regression testing 保障 UI 一致性

## 自测汇总

- [ ] 能用八种定位方式稳定查找页面元素
- [ ] 能搭建 Page Object 分层框架
- [ ] 能编写 Pytest fixture 管理测试前置/后置
- [ ] 能区分并正确使用三种等待策略
- [ ] 能用 Playwright 完成网络请求拦截与断言
- [ ] 能搭建跨浏览器并行执行环境
