# 项目2-竞赛模拟赛

> 覆盖模块：全部（GZ034 竞赛模拟）
> 预计用时：3 小时（模拟真实竞赛时间）
> 难度等级：高

---

## 1. 项目概述

### 1.1 项目背景

本项目模拟 GZ034 软件测试技能竞赛的完整流程，要求在规定时间内独立完成功能测试、自动化测试、性能测试、单元测试、接口测试及综合展示全部模块。

### 1.2 竞赛规则

| 规则项 | 说明 |
|--------|------|
| 时间限制 | 180 分钟（3小时） |
| 答题方式 | 独立完成，不查阅资料，不与他人交流 |
| 评分依据 | 按真实竞赛评分标准自评 |
| 环境要求 | 本地测试环境已部署，需求文档已提供 |

### 1.3 前置条件

- 熟悉测试用例设计方法（等价类、边界值、因果图、场景法）
- 掌握 Python + Selenium 自动化测试
- 掌握 JMeter 性能测试基础
- 掌握 JUnit 单元测试框架
- 掌握 Postman 接口测试
- 具备 PPT 制作与汇报能力
