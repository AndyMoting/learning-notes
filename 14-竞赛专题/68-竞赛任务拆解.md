# 68-竞赛任务拆解
> 课时：30 min | 难度：★★

## 学习目标
- 掌握 GZ034 赛项整体结构与五大任务分值分布
- 理解各任务评分要点与时间分配策略
- 学会 3-4 人团队角色分工与协作节奏

## 核心概念

### GZ034 赛项结构

| 任务 | 名称 | 分值 | 核心交付物 |
|------|------|------|-----------|
| 任务一 | 功能测试 | 45 分 | 测试计划、测试用例、Bug 报告、测试报告 |
| 任务二 | 自动化测试 | 15 分 | 4 道 Selenium 脚本题 |
| 任务三 | 性能测试 | 15 分 | JMeter/LoadRunner 脚本与报告 |
| 任务四 | 单元测试 | 10 分 | JUnit 测试类与覆盖率 |
| 任务五 | API 测试 | 10 分 | Postman 集合与数据驱动 |
| 职业素养 | 专业质量 | 5 分 | 文档规范、命名统一、排版整洁 |
| **合计** | | **100 分** | |

### 各任务评分细则

**任务一：功能测试（45 分）**
- 测试计划：8 分（目标、范围、策略、资源、进度、风险）
- 测试用例：15 分（覆盖度、步骤清晰、预期结果明确）
- Bug 报告：12 分（复现步骤、严重等级、实际/预期结果）
- 测试报告：10 分（概述、缺陷统计、结论、建议）

**任务二：自动化测试（15 分）**
- Q1 基础脚本：3 分
- Q2 unittest 框架：3 分
- Q3 数据驱动（ddt）：4 分
- Q4 Page Object 框架：4 分
- 运行结果与报告：1 分

**任务三：性能测试（15 分）**
- 测试脚本：6 分
- 场景设计：4 分
- 结果分析：3 分
- 报告截图：2 分

**任务四：单元测试（10 分）**
- 代码分析：2 分
- 测试数据设计：3 分
- JUnit 测试类：3 分
- 覆盖率达标：2 分

**任务五：API 测试（10 分）**
- 请求构建：3 分
- 数据驱动：3 分
- Token 关联：2 分
- 结果断言：2 分

### 时间分配策略（180 分钟）

| 阶段 | 时长 | 内容 |
|------|------|------|
| 审题与分工 | 10 min | 通读题目、分配角色、确认环境 |
| 任务一 | 70 min | 计划 15min + 用例 25min + Bug 20min + 报告 10min |
| 任务二 | 35 min | Q1 5min + Q2 8min + Q3 8min + Q4 14min |
| 任务三 | 30 min | 脚本 15min + 场景 8min + 报告 7min |
| 任务四 | 15 min | 分析 3min + 编码 10min + 验证 2min |
| 任务五 | 15 min | 请求 5min + 驱动 5min + 断言 5min |
| 检查与收尾 | 5 min | 命名规范、文件完整性、提交确认 |

### 团队角色分配（3-4 人）

**3 人团队：**
- A：任务一（功能测试）+ 文档统筹
- B：任务二（自动化）+ 任务四（单元测试）
- C：任务三（性能测试）+ 任务五（API 测试）

**4 人团队：**
- A：测试计划 + 测试报告
- B：测试用例 + Bug 报告
- C：自动化 + 单元测试
- D：性能测试 + API 测试

## 动手实操

1. 下载 GZ034 官方样题，打印评分表
2. 按上述时间分配进行 3 次模拟计时
3. 记录每次各任务实际耗时，调整个人节奏
4. 制作团队分工确认单，赛前签字确认

## 常见坑
- 任务一耗时过长挤压后续任务——严格执行 70 分钟上限
- 自动化题从 Q4 开始做——按顺序作答，Q1-Q3 是送分题
- 性能测试只写脚本不截图——Dashboard 报告截图占 2 分
- 职业素养分忽略——统一命名、字体、排版即可拿满 5 分
- 最后 5 分钟才检查——每完成一个任务立即自查命名与格式
