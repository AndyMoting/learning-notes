### Q1 基础脚本（4 分）

**考点：** WebDriver 基本操作（打开页面、定位元素、操作元素、关闭浏览器）

**评分点：**
- driver.get() 打开指定 URL：1 分
- find_element 定位元素：1 分
- click()/send_keys() 操作元素：1 分
- driver.quit() 关闭浏览器：1 分

**模板：**

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("http://target-url.com")
driver.find_element(By.ID, "element-id").click()
driver.quit()
```

### Q2 unittest 框架（4 分）

**考点：** unittest 框架结构（setUp/tearDown/test 方法）

**评分点：**
- setUp 中初始化 driver：1 分
- tearDown 中关闭 driver：1 分
- 至少 2 个 test 方法：2 分

**模板：**

```python
import unittest
from selenium import webdriver
from selenium.webdriver.common.by import By

class LoginTest(unittest.TestCase):
    def setUp(self):
        self.driver = webdriver.Chrome()
        self.driver.get("http://target-url.com/login")

    def test_valid_login(self):
        self.driver.find_element(By.ID, "username").send_keys("admin")
        self.driver.find_element(By.ID, "password").send_keys("123456")
        self.driver.find_element(By.ID, "login-btn").click()
        self.assertIn("首页", self.driver.title)

    def test_invalid_login(self):
        self.driver.find_element(By.ID, "username").send_keys("wrong")
        self.driver.find_element(By.ID, "password").send_keys("wrong")
        self.driver.find_element(By.ID, "login-btn").click()
        self.assertIn("登录", self.driver.title)

    def tearDown(self):
        self.driver.quit()

if __name__ == "__main__":
    unittest.main()
```

### Q3 数据驱动 ddt（4 分）

**考点：** @ddt + @data + @unpack + CSV 数据源 + assertEqual

**评分点：**
- @ddt 装饰器：1 分
- @data + @unpack 传参：1 分
- CSV 文件读取数据：1 分
- assertEqual 断言：1 分

**模板：**

```python
import unittest
import csv
from ddt import ddt, data, unpack
from selenium import webdriver
from selenium.webdriver.common.by import By

def read_csv(filename):
    data_list = []
    with open(filename, 'r', encoding='utf-8') as f:
        reader = csv.reader(f)
        next(reader)
        for row in reader:
            data_list.append(row)
    return data_list

@ddt
class SearchTest(unittest.TestCase):
    def setUp(self):
        self.driver = webdriver.Chrome()
        self.driver.get("http://target-url.com/search")

    @data(*read_csv('test_data.csv'))
    @unpack
    def test_search(self, keyword, expected_result):
        self.driver.find_element(By.ID, "search-input").clear()
        self.driver.find_element(By.ID, "search-input").send_keys(keyword)
        self.driver.find_element(By.ID, "search-btn").click()
        result = self.driver.find_element(By.ID, "result").text
        self.assertEqual(expected_result, result)

    def tearDown(self):
        self.driver.quit()

if __name__ == "__main__":
    unittest.main()
```

**CSV 文件（test_data.csv）：**

```csv
keyword,expected_result
手机,手机 - 搜索结果
电脑,电脑 - 搜索结果
平板,平板 - 搜索结果
```

### Q4 Page Object 框架（7 分）

**考点：** PO 三层架构（BasePage → 页面类 → 测试类 → 运行入口）

**评分点：**
- BasePage 基类封装：1 分
- 页面类继承 BasePage：2 分
- 测试类调用页面对象：2 分
- 运行入口与断言：2 分

**完整 8 文件模板：**

**文件 1：base_page.py**

```python
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

class BasePage:
    def __init__(self, driver):
        self.driver = driver

    def find_element(self, locator, timeout=10):
        return WebDriverWait(self.driver, timeout).until(
            EC.presence_of_element_located(locator)
        )

    def click(self, locator):
        self.find_element(locator).click()

    def input_text(self, locator, text):
        element = self.find_element(locator)
        element.clear()
        element.send_keys(text)

    def get_text(self, locator):
        return self.find_element(locator).text

    def get_title(self):
        return self.driver.title
```

**文件 2：login_page.py**

```python
from selenium.webdriver.common.by import By
from base_page import BasePage

class LoginPage(BasePage):
    USERNAME_INPUT = (By.ID, "username")
    PASSWORD_INPUT = (By.ID, "password")
    LOGIN_BUTTON = (By.ID, "login-btn")
    WELCOME_MSG = (By.ID, "welcome")

    def input_username(self, username):
        self.input_text(self.USERNAME_INPUT, username)

    def input_password(self, password):
        self.input_text(self.PASSWORD_INPUT, password)

    def click_login(self):
        self.click(self.LOGIN_BUTTON)

    def get_welcome_text(self):
        return self.get_text(self.WELCOME_MSG)
```
