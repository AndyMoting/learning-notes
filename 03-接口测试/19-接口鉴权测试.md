## 核心概念

### JWT（JSON Web Token）

JWT 由三段组成，以 `.` 分隔：

```
Header.Payload.Signature
```

| 段 | 内容 | 示例 |
|---|---|---|
| Header | 令牌类型 + 签名算法 | `{"alg":"HS256","typ":"JWT"}` |
| Payload | 声明（用户信息、过期时间等） | `{"sub":"123","exp":1700000000}` |
| Signature | HMACSHA256(base64(header)+"."+base64(payload), secret) | 签名结果 |

**关键特性：**
- Base64URL 编码，非加密——Payload 可被解码查看
- 服务端通过 Signature 验证令牌未被篡改
- `exp` 字段为过期时间戳（Unix epoch 秒）

### Session-Cookie 机制

```
客户端                              服务器
  |                                  |
  |--- POST /login ----------------->|
  |<-- Set-Cookie: sessionid=abc ----|
  |--- GET /profile ---------------->|
  |    Cookie: sessionid=abc         |
  |<-- 200 OK + 用户数据 ------------|
```

服务器通过 `Set-Cookie` 响应头下发 session ID，客户端后续请求通过 `Cookie` 请求头发回。

### OAuth 2.0 Authorization Code Flow

```
客户端    用户    授权服务器    资源服务器
 |         |         |            |
 |---(A)请求授权---->|            |
 |         |<--(B)登录授权--------|
 |<--(C)返回授权码---|            |
 |---(D)授权码换token----------->|
 |<--(E)返回access_token---------|
 |---(F)带token请求资源---------->|
 |<--(G)返回受保护资源------------|
```

### API Key 鉴权

最简单的鉴权方式，通过请求头或请求参数传递：

```http
GET /api/data HTTP/1.1
Host: example.com
X-API-Key: sk-abc123def456
```

## 动手实操

### JWT 测试场景

| 用例编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| JWT-001 | 空令牌 | 请求头不携带 Authorization | 401 Unauthorized |
| JWT-002 | 错误令牌 | Authorization: Bearer invalid_token | 401 |
| JWT-003 | 过期令牌 | 使用已过期的 JWT | 401 |
| JWT-004 | 畸形令牌 | 删除 Signature 段 | 401 |
| JWT-005 | 算法混淆 | Header 中 alg 改为 none | 401（服务端应拒绝） |
| JWT-006 | Payload 篡改 | 修改 Payload 中用户角色字段 | 401（签名校验失败） |
| JWT-007 | 有效令牌 + 正确权限 | 正常令牌访问授权资源 | 200 |

### ShopTest 鉴权测试完整代码

```python
import requests
import jwt
import time
import json
import pytest

BASE_URL = "http://localhost:8000/api"
SECRET_KEY = "your-secret-key"

class TestAuth:
    """接口鉴权测试 - ShopTest"""

    @pytest.fixture
    def valid_token(self):
        payload = {"user_id": 1, "role": "user", "exp": int(time.time()) + 3600}
        return jwt.encode(payload, SECRET_KEY, algorithm="HS256")

    @pytest.fixture
    def expired_token(self):
        payload = {"user_id": 1, "role": "user", "exp": int(time.time()) - 100}
        return jwt.encode(payload, SECRET_KEY, algorithm="HS256")

    # ========== 负面用例 ==========

    def test_empty_token(self):
        """空令牌 - 请求头不包含 Authorization"""
        resp = requests.get(f"{BASE_URL}/orders")
        assert resp.status_code == 401
        assert "credentials" in resp.json()["detail"].lower() or "未授权" in resp.json()["detail"]

    def test_wrong_token(self):
        """错误令牌 - 伪造的 JWT"""
        headers = {"Authorization": "Bearer eyJhbGciOiJIUzI1NiJ9.invalid.signature"}
        resp = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp.status_code == 401

    def test_expired_token(self, expired_token):
        """过期令牌 - JWT exp 字段已过"""
        headers = {"Authorization": f"Bearer {expired_token}"}
        resp = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp.status_code == 401
        assert "expired" in resp.json()["detail"].lower() or "过期" in resp.json()["detail"]

    def test_malformed_token_missing_signature(self):
        """畸形令牌 - 删除 Signature 段"""
        # 只保留 Header.Payload
        parts = jwt.encode({"user_id": 1}, SECRET_KEY, algorithm="HS256").split(".")
        malformed = f"{parts[0]}.{parts[1]}."
        headers = {"Authorization": f"Bearer {malformed}"}
        resp = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp.status_code == 401

    def test_payload_tampered(self):
        """Payload 篡改 - 修改角色字段后不重新签名"""
        parts = jwt.encode({"user_id": 1, "role": "user", "exp": int(time.time()) + 3600}, SECRET_KEY, algorithm="HS256").split(".")
        # 解码 payload，修改角色，重新 encode 但不签名
        import base64
        payload_data = json.loads(base64.urlsafe_b64decode(parts[1] + "=="))
        payload_data["role"] = "admin"
        new_payload = base64.urlsafe_b64encode(json.dumps(payload_data).encode()).rstrip(b"=").decode()
        tampered_token = f"{parts[0]}.{new_payload}.{parts[2]}"
        headers = {"Authorization": f"Bearer {tampered_token}"}
        resp = requests.get(f"{BASE_URL}/admin/users", headers=headers)
        assert resp.status_code == 403  # 签名校验失败或权限不足

    def test_algorithm_none_attack(self):
        """alg=none 攻击 - 尝试绕过签名校验"""
        header = base64.urlsafe_b64encode(json.dumps({"alg": "none", "typ": "JWT"}).encode()).rstrip(b"=").decode()
        payload = base64.urlsafe_b64encode(json.dumps({"user_id": 1, "role": "admin"}).encode()).rstrip(b"=").decode()
        none_token = f"{header}.{payload}."
        headers = {"Authorization": f"Bearer {none_token}"}
        resp = requests.get(f"{BASE_URL}/admin/users", headers=headers)
        assert resp.status_code == 401

    def test_insufficient_permissions(self, valid_token):
        """权限不足 - 普通用户访问管理员接口"""
        headers = {"Authorization": f"Bearer {valid_token}"}
        resp = requests.get(f"{BASE_URL}/admin/users", headers=headers)
        assert resp.status_code == 403

    # ========== 正面用例 ==========

    def test_valid_token_access_granted(self, valid_token):
        """有效令牌访问受保护资源"""
        headers = {"Authorization": f"Bearer {valid_token}"}
        resp = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp.status_code == 200

    def test_role_based_access(self, valid_token):
        """角色权限校验 - 登录用户能有访问需登录的接口"""
        headers = {"Authorization": f"Bearer {valid_token}"}
        resp = requests.get(f"{BASE_URL}/profile", headers=headers)
        assert resp.status_code == 200
        assert resp.json()["user_id"] == 1

    # ========== 会话管理 ==========

    def test_session_invalidation_after_logout(self):
        """登出后会话失效"""
        # 登录获取 token
        login_resp = requests.post(f"{BASE_URL}/login", json={
            "username": "testuser",
            "password": "Test@1234"
        })
        token = login_resp.json()["access_token"]

        # 使用 token 访问资源
        headers = {"Authorization": f"Bearer {token}"}
        resp1 = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp1.status_code == 200

        # 登出
        requests.post(f"{BASE_URL}/logout", headers=headers)

        # 再次使用同一 token
        resp2 = requests.get(f"{BASE_URL}/orders", headers=headers)
        assert resp2.status_code == 401
```

### API Key 测试

```python
class TestApiKey:
    """API Key 鉴权测试"""

    def test_missing_api_key(self):
        """缺少 API Key"""
        resp = requests.get(f"{BASE_URL}/products")
        assert resp.status_code == 403

    def test_invalid_api_key(self):
        """无效的 API Key"""
        headers = {"X-API-Key": "wrong-key-123"}
        resp = requests.get(f"{BASE_URL}/products", headers=headers)
        assert resp.status_code == 403

    def test_valid_api_key(self):
        """有效的 API Key"""
        headers = {"X-API-Key": "sk-valid-key-789"}
        resp = requests.get(f"{BASE_URL}/products", headers=headers)
        assert resp.status_code == 200
```

## 常见坑

1. **JWT Secret 硬编码**：测试环境 Secret 与生产不一致导致签名验证通过但逻辑异常
2. **忽略 exp 校验**：服务端未校验过期时间，需额外编写过期用例暴露问题
3. **大小写敏感**：Authorization Header 中 `Bearer` 大小写错误导致解析失败
4. **Token 泄漏**：日志或测试报告中记录真实 Token，应脱敏处理
5. **并发登录测试不足**：同一账号多端登录的 token 互斥或共存策略未覆盖
6. **状态码混淆**：401（未认证）与 403（无权限）返回场景混淆
