## 学习目标

- 理解移动端测试与 Web 端测试的核心差异和测试类型
- 使用 ADB 命令进行设备管理、日志抓取、性能采样
- 搭建 Appium 自动化测试环境（Android/iOS）
- 使用 Appium 定位元素、执行手势操作和处理混合应用
- 设计移动端并行执行策略与测试报告体系
