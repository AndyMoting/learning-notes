## 学习目标

- 将 Page Object、Factory、Strategy 等设计模式应用于测试框架
- 设计可配置、可扩展的分层自动化测试框架
- 开发测试工具（CLI、Mock Server、数据生成器）提升团队效率
- 建立代码质量门禁（lint/coverage/bandit）保障测试代码品质
- 将自动化测试嵌入 CI/CD 流水线各阶段
- 构建覆盖鉴权、契约、数据驱动的 API 自动化测试体系

- [ ] 能设计配置驱动的分层测试框架

- [ ] 能配置质量门禁（pytest-cov/flake8）
- [ ] 能在 CI 中实现测试门禁和失败通知
- [ ] 能搭建含鉴权、数据驱动、报告生成的 API 测试框架
