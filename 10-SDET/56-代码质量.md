> 课时：45 min | 难度：★★★☆☆

## 学习目标

- 掌握 Python 代码质量工具链配置

- 配置 pre-commit hooks 自动化质量检查

## 核心概念

### 测试代码质量工具链

```
源代码 → Linter → Formatter → Type Checker → Unit Test → Pre-commit
           ↓           ↓            ↓             ↓           ↓
        flake8      black       mypy         pytest     pre-commit
        pylint      isort       pyright      coverage   git hooks
```

### 工具分工

| 工具 | 类别 | 用途 |
|------|------|------|
| flake8 | Linter | 代码风格检查（PEP 8） |
| pylint | Linter | 深度代码分析（复杂度/设计） |
| black | Formatter | 自动格式化（无配置争论） |
| isort | Formatter | import 排序 |
| mypy | Type Checker | 静态类型检查 |
| pyright | Type Checker | 微软出品，更快的类型检查 |
| coverage.py | Coverage | 代码覆盖率统计 |
| pre-commit | Git Hook | 提交前自动检查 |

```python
# 类型注解示例 - 测试代码中的类型标注

from typing import Dict, List, Optional, Tuple, Any, Protocol
from dataclasses import dataclass
from selenium.webdriver.remote.webdriver import WebDriver
from selenium.webdriver.remote.webelement import WebElement


# 1. 类型别名
Locator = Tuple[str, str]  # (By.XXX, "value")
TestResult = Dict[str, Any]
TestData = Dict[str, Any]


# 2. 数据类
@dataclass
class UserCredentials:
    username: str
    password: str
    role: str = "user"


@dataclass
class APIResponse:
    status_code: int
    body: Dict[str, Any]
    headers: Dict[str, str]
    elapsed_ms: float


# 3. Protocol（结构化子类型）
class Loggable(Protocol):
    """可日志记录的协议"""
    def log(self, message: str) -> None:
        ...


class Serializable(Protocol):
    """可序列化的协议"""
    def to_dict(self) -> Dict[str, Any]:
        ...


# 4. 泛型函数
def find_all_by_locator(
    driver: WebDriver, 
    locator: Locator
) -> List[WebElement]:
    """查找所有匹配元素"""
    return driver.find_elements(*locator)


def wait_for_element(
    driver: WebDriver,
    locator: Locator,
    timeout: int = 10,
    poll_frequency: float = 0.5
) -> Optional[WebElement]:
    """等待元素出现，超时返回 None"""
    from selenium.webdriver.support.ui import WebDriverWait
    from selenium.webdriver.support import expected_conditions as EC
    
    try:
        return WebDriverWait(driver, timeout, poll_frequency).until(
            EC.presence_of_element_located(locator)
        )
    except Exception:
        return None


# 5. 带类型标注的测试函数
def test_user_login(
    driver: WebDriver,
    credentials: UserCredentials
) -> None:
    """测试用户登录"""
    login_page = LoginPage(driver)
    login_page.navigate_to()
    login_page.login(credentials.username, credentials.password)
    assert login_page.is_logged_in()


def batch_validate_users(
    users: List[Dict[str, Any]]
) -> Tuple[List[str], List[str]]:
    """
    批量验证用户数据
    
    Returns:
        (有效用户列表, 错误信息列表)
    """
    valid: List[str] = []
    errors: List[str] = []
    
    for user in users:
        if _is_valid_user(user):
            valid.append(user["email"])
        else:
            errors.append(f"无效用户: {user.get('email', 'unknown')}")
    
    return valid, errors


def _is_valid_user(user: Dict[str, Any]) -> bool:
    """验证用户数据有效性"""
    required_fields = ["email", "username", "password"]
    return all(field in user and user[field] for field in required_fields)
```

```python
class TestPhoneValidator:
    """手机号验证器测试"""
    
    @pytest.mark.parametrize("phone,expected", [

        ("15912345678", True),
        ("12345678901", False),  # 非正常号段
        ("1380013800", False),   # 少一位
        ("138001380001", False), # 多一位
        ("", False),
    ])

        assert validate_phone(phone) == expected


class TestInputSanitizer:
    """输入清洗测试"""
    
    def test_xss_prevention(self):
        """XSS 攻击防护"""
        malicious = '<script>alert("xss")</script>'
        result = sanitize_input(malicious)
        assert "<script>" not in result
        assert "&lt;script&gt;" in result
    
    def test_sql_injection_prevention(self):
        """SQL 注入防护"""
        malicious = "'; DROP TABLE users; --"
        result = sanitize_input(malicious)
        assert "DROP TABLE" not in result
    
    def test_normal_input_unchanged(self):
        """正常输入不受影响"""
        normal = "用户名_test123"
        assert sanitize_input(normal) == normal
```

### 实操4：Pre-commit Hooks 配置

```yaml
# .pre-commit-config.yaml
# 安装: pip install pre-commit
# 初始化: pre-commit install
# 手动运行: pre-commit run --all-files

default_language_version:
  python: python3.11

repos:
  # 基础检查
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace        # 行尾空格
      - id: end-of-file-fixer          # 文件末尾空行
      - id: check-yaml                 # YAML 语法
      - id: check-json                 # JSON 语法
      - id: check-toml                 # TOML 语法
      - id: check-merge-conflict       # 合并冲突标记
      - id: check-added-large-files    # 大文件检查（>500KB）
        args: ['--maxkb=500']
      - id: debug-statements            # 遗留的调试语句
        args: ['--ignore=ipdb']

  # import 排序
  - repo: https://github.com/pycqa/isort
    rev: 5.13.2
    hooks:
      - id: isort
        args: ["--profile", "black"]

  # 代码格式化
  - repo: https://github.com/psf/black
    rev: 24.3.0
    hooks:
      - id: black
        args: ["--line-length", "100"]

  # Linter
  - repo: https://github.com/pycqa/flake8
    rev: 7.0.0
    hooks:
      - id: flake8
        additional_dependencies:
          - flake8-bugbear
          - flake8-comprehensions
          - flake8-docstrings

  # 类型检查
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.9.0
    hooks:
      - id: mypy
        additional_dependencies:
          - types-requests
          - types-PyYAML
        args: ["--ignore-missing-imports"]

  # 安全扫描
  - repo: https://github.com/PyCQA/bandit
    rev: 1.7.8
    hooks:
      - id: bandit
        args: ["-c", "pyproject.toml"]
        additional_dependencies: ["bandit[toml]"]

  # pytest 快速检查
  - repo: local
    hooks:
      - id: pytest-check
        name: pytest-check
        entry: pytest tests/test_utils/ -x -q --tb=short
        language: system
        pass_filenames: false
        always_run: true
        stages: [commit]
```

### 实操5：代码审查清单

```markdown
# 测试代码审查清单 (Code Review Checklist)

## 正确性
- [ ] 测试断言验证的是行为而非实现细节
- [ ] 测试数据独立，不依赖执行顺序
- [ ] 异步操作有正确的等待/超时处理
- [ ] 边界条件和异常路径有覆盖

## 可维护性
- [ ] 测试名称清晰描述意图（test_<场景>_<预期行为>）
- [ ] 无重复代码（提取到 fixture/helper）
- [ ] Page Object 不包含断言逻辑
- [ ] 测试步骤有适当的日志记录

## 性能
- [ ] 无不必要的 sleep（使用显式等待替代）
- [ ] 测试数据构造不成为瓶颈
- [ ] 并行执行安全（无共享可变状态）

## 类型安全
- [ ] 函数参数和返回值有类型标注
- [ ] 复杂数据结构使用 dataclass/NamedTuple
- [ ] mypy 检查无错误

## 风格
- [ ] 通过 flake8 + black 格式化
- [ ] import 已排序（isort）
- [ ] 无遗留调试代码（print/pdb）
- [ ] 魔法数字提取为命名常量
```

## 常见坑

1. **测试代码不需要质量**：测试代码同样需要维护，低质量测试成为负担
2. **类型标注过度**：为标注而标注导致代码可读性下降——公共 API 必须标注，内部实现适度
3. **pre-commit 太慢**：全量检查导致提交等待过长——只检查暂存文件
4. **mypy 过于严格**：`disallow_untyped_defs` 导致大量第三方库报错——合理配置 ignore
5. **测试的测试过度**：为简单的 getter/setter 写单元测试——聚焦复杂逻辑
