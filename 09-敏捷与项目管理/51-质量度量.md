## 核心概念

### 代码覆盖率

代码覆盖率衡量测试执行时覆盖了多少代码。三种类型：

**行覆盖率（Line Coverage）**：
```
行覆盖率 = 已执行代码行数 / 可执行代码总行数 × 100%
```
最简单常用，但无法检测条件分支的覆盖情况。

**分支覆盖率（Branch Coverage）**：
```
分支覆盖率 = 已执行分支数 / 总分支数 × 100%
```
每个 if/else、switch/case 的分支路径都被独立统计。

**路径覆盖率（Path Coverage）**：
```
路径覆盖率 = 已执行路径数 / 总路径数 × 100%
```
追踪从入口到出口的所有可能执行路径，指数级增长，实践中很少达到 100%。

### 缺陷度量

| 指标 | 公式 | 用途 |
|------|------|------|
| 缺陷密度 | 缺陷数 / KLOC 或功能点 | 衡量模块质量 |
| 缺陷逃逸率 | 生产环境缺陷 / 总缺陷 × 100% | 衡量测试有效性 |
| 缺陷引入率 | 每 Sprint 新增缺陷数 | 衡量开发质量趋势 |
| 严重程度分布 | 各等级缺陷占比 | 评估风险聚焦点 |

### DORA 指标

DORA（DevOps Research and Assessment）四项核心指标：

| 指标 | 精英团队标准 | 描述 |
|------|-------------|------|
| 部署频率 | 按需（每天多次） | 代码部署到生产的频率 |
| 变更前置时间 | < 1 小时 | 从提交到生产运行的时间 |
| 平均恢复时间（MTTR） | < 1 小时 | 从故障到恢复的时间 |
| 变更失败率 | < 5% | 导致故障的部署占总部署的比例 |

### 测试运行指标

```
通过率 = 通过用例数 / 总用例数 × 100%
执行效率 = 用例数 / 执行时间（用例/分钟）
不稳定性 = 重跑通过次数 / 总执行次数 × 100%
维护成本 = 维护测试代码时间 / 总工程时间 × 100%
```

### 实操3：质量数据收集脚本

```python
# quality_metrics.py
"""质量度量数据收集与分析"""

from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import List, Dict
import json


@dataclass
class DefectRecord:
    defect_id: str
    severity: str  # critical, major, minor, trivial
    found_phase: str  # unit_test, integration, e2e, production
    created_at: datetime
    resolved_at: datetime = None
    
    @property
    def resolution_hours(self) -> float:
        if self.resolved_at:
            return (self.resolved_at - self.created_at).total_seconds() / 3600
        return None


class QualityMetricsCollector:
    """质量度量收集器"""
    
    def __init__(self):
        self.defects: List[DefectRecord] = []
        self.test_runs: List[Dict] = []
        self.deployments: List[Dict] = []
    
    def add_defect(self, defect: DefectRecord):
        self.defects.append(defect)
    
    def defect_density(self, kloc: float) -> float:
        """每千行代码缺陷密度"""
        if kloc == 0:
            return 0
        return len(self.defects) / kloc
    
    def escape_rate(self) -> float:
        """缺陷逃逸率"""
        total = len(self.defects)
        if total == 0:
            return 0.0
        prod_defects = sum(1 for d in self.defects if d.found_phase == "production")
        return prod_defects / total * 100
    
    def severity_distribution(self) -> Dict[str, int]:
        """严重程度分布"""
        distribution = {}
        for d in self.defects:
            distribution[d.severity] = distribution.get(d.severity, 0) + 1
        return distribution
    
    def test_pass_rate(self) -> float:
        """测试通过率"""
        if not self.test_runs:
            return 0.0
        total = sum(r["total"] for r in self.test_runs)
        passed = sum(r["passed"] for r in self.test_runs)
        return (passed / total * 100) if total > 0 else 0.0
    
    def flakiness_rate(self) -> float:
        """测试不稳定性（flakiness）"""
        if not self.test_runs:
            return 0.0
        total = sum(r["total"] for r in self.test_runs)
        flaky = sum(r.get("flaky_count", 0) for r in self.test_runs)
        return (flaky / total * 100) if total > 0 else 0.0
    
    def avg_lead_time_hours(self) -> float:
        """平均变更前置时间"""
        if not self.deployments:
            return 0.0
        times = [
            (d["deployed_at"] - d["committed_at"]).total_seconds() / 3600
            for d in self.deployments
        ]
        return sum(times) / len(times)
    
    def generate_report(self) -> Dict:
        """生成质量报告"""
        report = {
            "generated_at": datetime.now().isoformat(),
            "summary": {
                "total_defects": len(self.defects),
                "defect_escape_rate": f"{self.escape_rate():.1f}%",
                "severity_distribution": self.severity_distribution(),
            },
            "test_quality": {
                "pass_rate": f"{self.test_pass_rate():.1f}%",
                "flakiness_rate": f"{self.flakiness_rate():.1f}%",
            },
            "delivery": {
                "avg_lead_time_hours": f"{self.avg_lead_time_hours():.1f}",
            }
        }
        return report


# 使用示例
if __name__ == "__main__":
    collector = QualityMetricsCollector()
    
    # 添加缺陷数据
    collector.add_defect(DefectRecord(
        defect_id="BUG-001",
        severity="critical",
        found_phase="production",
        created_at=datetime(2026, 7, 10),
        resolved_at=datetime(2026, 7, 10, 2, 30)
    ))
    collector.add_defect(DefectRecord(
        defect_id="BUG-002",
        severity="major",
        found_phase="integration",
        created_at=datetime(2026, 7, 12),
        resolved_at=datetime(2026, 7, 12, 1, 15)
    ))
    
    # 添加测试运行数据
    collector.test_runs.append({
        "date": "2026-07-15",
        "total": 150,
        "passed": 147,
        "failed": 3,
        "flaky_count": 2
    })
    
    # 添加部署数据
    collector.deployments.append({
        "version": "v2.1.0",
        "committed_at": datetime(2026, 7, 15, 9, 0),
        "deployed_at": datetime(2026, 7, 15, 9, 25)
    })
    
    report = collector.generate_report()
    print(json.dumps(report, indent=2, ensure_ascii=False))
```

## 常见坑

1. **覆盖率虚荣指标**：追求 100% 行覆盖率而忽视测试有效性——覆盖不等于正确验证
2. **度量孤岛**：指标分散在各工具中，缺乏统一视图
3. **阈值一刀切**：所有模块使用相同覆盖率阈值，忽视核心/非核心差异
4. **忽视趋势**：只看单点数据不分析趋势——覆盖率从 80% 降到 60% 比持续在 60% 更危险
5. **度量滥用**：将指标用于个人绩效考核，导致数据注水
