## 学习目标

- 使用 Git Flow 分支模型协作管理测试资产（用例/脚本/配置）
- 使用 GitHub Actions 搭建 CI 流水线实现测试自动触发与报告
- 理解 CD 基本概念并能搭建简单的持续部署流程
- 使用 Docker 容器化测试环境与依赖服务
- 使用 Docker Compose 一键编排多服务测试环境

## 自测汇总

- [ ] 能使用 Git Flow 管理 feature/release/hotfix 分支
- [ ] 能编写 GitHub Actions YAML 实现 push 触发测试
- [ ] 能用 Dockerfile 构建测试环境镜像
- [ ] 能用 Docker Compose 编排含数据库和 Mock 服务的测试环境
- [ ] 能解读 CI 流水线执行结果并定位失败原因
