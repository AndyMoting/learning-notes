## 二、测试用例模板

| 字段 | 说明 |
|------|------|
| 用例编号 | 模块缩写-序号（如 LOGIN-001） |
| 所属模块 | 功能模块名称 |
| 用例标题 | 简明描述测试点 |
| 前置条件 | 执行用例前需满足的条件 |
| 测试步骤 | 1. <br>2. <br>3. |
| 测试数据 | 输入值/参数 |
| 预期结果 | 系统应返回的正确结果 |

## 三、Bug报告模板

| 要素 | 内容 |
|------|------|
| **Bug编号** | BUG-模块-序号（如 BUG-LOGIN-001） |
| **所属模块** | |
| **Bug标题** | 简明描述缺陷现象 |
| **严重程度** | 致命/严重/一般/轻微 |
| **复现步骤** | 1. <br>2. <br>3. |
| **测试数据** | |
| **预期结果** | |
| **实际结果** | |
| **附件** | 截图/录屏/日志 |
| **环境信息** | 操作系统：<br>浏览器：<br>版本号： |

### Bug严重程度定义

| 等级 | 定义 | 示例 |
|------|------|------|
| 致命 | 系统崩溃/数据丢失/核心功能不可用 | 支付后订单未生成且扣款成功 |
| 严重 | 主要功能错误/无替代方案 | 登录功能完全失效 |
| 一般 | 次要功能错误/有替代方案 | 搜索排序不正确 |
| 轻微 | UI显示问题/提示语错误 | 文字错位、错别字 |

### Bug报告示例

| 要素 | 内容 |
|------|------|
| **Bug编号** | BUG-LOGIN-005 |
| **所属模块** | 登录模块 |
| **Bug标题** | 连续5次输入错误密码后账户未锁定 |
| **严重程度** | 严重 |
| **复现步骤** | 1. 打开登录页<br>2. 输入正确用户名<br>3. 连续5次输入错误密码<br>4. 观察系统响应 |
| **测试数据** | 用户名：test01<br>密码：wrongpwd |
| **预期结果** | 第5次错误后账户锁定30分钟，提示"账户已锁定" |
| **实际结果** | 账户未锁定，可继续尝试登录 |
| **附件** | 截图_登录异常.png |
| **环境信息** | Windows 11 / Chrome 120 / v2.3.1 |
