# GZ034 三个月冲刺训练计划

> 目标：从入门到参赛 | 周期：12 周 | 每日：2-4 小时

## 阶段划分

### 第1-4周：基础速成

| 周 | 内容 | 产出 |
|---|------|------|
| W1 | 测试理论 + Python 速通 | 测试计划1份 + Python练习50题 |
| W2 | 功能测试 + 用例设计 | 手工用例100条 + Bug报告20个 |
| W3 | 接口测试（Postman+requests） | Postman集合5个 + requests脚本10个 |
| W4 | Selenium 基础 | 自动化脚本5个 + 月考1次 |

### 第5-8周：技能深化

| 周 | 内容 | 产出 |
|---|------|------|
| W5 | Selenium 进阶 + PO 框架 | PO框架1套 + 自动化4题模板 |
| W6 | JMeter 性能测试 | JMeter脚本3套 + 报告1份 |
| W7 | JUnit + Postman 竞赛题 | 单元测试4题 + 接口3题 |
| W8 | 综合串讲 + 月考 | 模拟赛1次 + 复盘报告 |

### 第9-12周：竞赛冲刺

| 周 | 内容 | 产出 |
|---|------|------|
| W9-10 | 高频模拟赛（6次） | 每次赛后复盘 |
| W11 | 赛题预研 + 5套公开题 | 5套题完整答案 |
| W12 | 赛前调整 + 比赛 | 错题回顾 + 轻量保持 |

## 每日作息

- 工作日：2-3 小时（理论1h + 实操1-2h）
- 周末：8-10 小时（模拟赛/项目实战）

## 检验标准

- 第4周：独立完成功能测试（3h，得分率>80%）
- 第8周：完整模拟赛（得分>70分）
- 第12周：模拟赛稳定80分以上
