## 使用方式

1. **按顺序学习**：每节包含 核心概念 → 动手实操 → 自测清单
2. **判断对错**：自测清单 + 参考答案 + 自动化验证（代码运行看结果）
3. **延伸阅读**：每节末尾有外部链接，按需深入
4. **综合项目**：每学完几个模块，完成一个综合项目检验成果

## 风格说明

- **教科书**：定义→原理→方法→案例，结构化层级
- **手册**：完整可执行的命令、代码、配置
- **笔记**：关键知识点用表格/清单/代码块呈现
- **无废话**：无场景引入、无emoji、无对话语气

## 推荐学习顺序

### 就业（主线）

```
01 测试理论 → 02 编程基础 → 03 接口测试 → 04 Web自动化
→ 06 性能测试 → 07 安全测试 → 08 DevOps → 09 敏捷
→ 10 SDET → 11 云测试 → 12 AI测试 → 13 面试
```

05 移动端测试是专项扩展，不在主干路径上。可在完成 04-Web自动化 之后，或整条主线学完后按岗位需要选学。

### 竞赛（重点模块）

```
01 测试理论 → 02 编程基础 → 03 接口测试 → 04 Web自动化
→ 06 性能测试 → 14 竞赛专题
```
